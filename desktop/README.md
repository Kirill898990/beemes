# beemes для Windows 10/11

Окно с веб-версией beemes (`https://beemes.ru/web/`). Переписка, шифрование, эмодзи, фото и звонки — это веб-версия,
поэтому приложение обновляется вместе с сайтом, переустанавливать не нужно.

Что добавляет приложение:

- своё окно и значок, ярлык на рабочем столе и в «Пуске»;
- **работа в трее**: закрытое окно прячется к часам, сообщения и звонки продолжают приходить;
- уведомления Windows о новых сообщениях; входящий звонок сам поднимает окно;
- мигание кнопки на панели задач при новых сообщениях;
- запуск вместе с Windows (тихо, в трей) — выключается в меню значка в трее;
- микрофон и камера для звонков (только для beemes), экран «Нет связи».

Адрес можно поменять переменной окружения `BEEMES_URL` (например, когда beemes переедет на beemes.ru —
тогда поменять и `SITE` в `main.js`, поднять `version` в `package.json`).

## Сборка

Установщик собирает GitHub (Actions → «Приложение для Windows»), когда меняется эта папка. Из ветки main готовый
`BeemesSetup.exe` выкладывается в Releases. На компьютере с Windows: `npm ci`, потом `npm start` или `npm run dist`.
Проверка правил без Electron: `node test.js`.

Установщик не подписан сертификатом, поэтому Windows может показать «Windows защитил ваш компьютер» →
«Подробнее» → «Выполнить в любом случае».

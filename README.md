# beemes 🐝

Мессенджер для Android: личные чаты, звонки и видеозвонки, фотографии, бесплатные анимированные эмодзи
и настраиваемые профили. Все сообщения шифруются на телефоне — сервер хранит только шифр.

- `android/` — приложение (Kotlin, Jetpack Compose).
- `server/` — сервер на PocketBase: база, правила доступа, push-уведомления, звонки, сайт-визитка, страница звонка
  и **веб-версия** (`server/pb_public/web`, открывается по адресу `/web/`).
- `desktop/` — **приложение для Windows 10/11**: окно с веб-версией, работа в трее, автозапуск. Установщик собирает GitHub.
- `tools/fetch_emoji.py` — скачивает анимированные эмодзи Noto (Google, CC BY 4.0) в приложение.

## Как устроено шифрование

| Что | Как |
|---|---|
| Ключи | У каждого пользователя пара X25519, создаётся на телефоне при регистрации |
| Ключ чата | HKDF-SHA256 от общего секрета X25519, соль — id чата |
| Сообщения | AES-256-GCM, текст и служебные поля внутри шифра; AAD = `чат|отправитель` |
| Фото | Свой случайный ключ AES-256-GCM на каждое фото; ключ лежит внутри зашифрованного сообщения |
| Пароль | На сервер уходит не пароль, а PBKDF2-SHA256 (210 000 итераций) от него |
| Новый телефон | Копия закрытого ключа на сервере закрыта паролем (PBKDF2 + AES-GCM) |
| Проверка | «Код безопасности» в профиле собеседника — 20 цифр из обоих открытых ключей |
| Звонки | WebRTC (DTLS-SRTP), при необходимости через свой TURN-сервер (coturn) |
| Push | Firebase получает только зашифрованный текст, расшифровывает телефон |

Сервер видит, кто с кем переписывается и когда (без этого не доставить сообщение), но не содержимое.

## Сервер

Нужен свой сервер (VDS) с Ubuntu 24.04 и свой домен. Сейчас beemes работает на `kbast.ru`
(позже переедет на `beemes.ru`). В DNS домена добавьте две A-записи с IP-адресом сервера:
`@` (сам домен) и `www`. Затем на сервере под root:

```bash
curl -fsSL https://raw.githubusercontent.com/Kirill898990/beemes/refs/heads/main/server/install.sh \
  | bash -s -- kbast.ru ПОЧТА_АДМИНИСТРАТОРА ПАРОЛЬ_АДМИНИСТРАТОРА
```

Что произойдёт:

1. beemes запустится в `/opt/beemes` на `127.0.0.1:8091` (служба `beemes`).
2. Поставится **Caddy**: он получает сертификаты https для домена и `www.` перед ним.
3. Поставится TURN-сервер для звонков (coturn) — через него идут звонки, когда телефоны не могут
   соединиться напрямую.

Если ставить beemes на сервер, где уже работает сайт «Простая химия», установка переведёт сайт школы
за тот же Caddy (его база не трогается) и возьмёт его TURN-сервер. Для этого у школы должна быть
версия с файлом `server/pb_hooks/proxy.pb.js`.

Повторный запуск той же команды обновляет beemes. Журналы: `journalctl -u beemes -f`, `journalctl -u caddy -f`.

### Push-уведомления (Firebase)

1. [console.firebase.google.com](https://console.firebase.google.com) → создать проект → добавить
   Android-приложение с пакетом `ru.beemes.app`.
2. Скачать `google-services.json` и положить в `android/app/` (в Git его нет). Без него приложение тоже
   собирается и работает, просто без уведомлений.
3. Настройки проекта → Сервисные аккаунты → «Создать закрытый ключ». Открыть панель администратора
   `https://kbast.ru/_/` → коллекция `bm_settings` → новая запись → вставить содержимое
   скачанного JSON в поле `firebaseKey`. Ключ никому не пересылайте и не кладите в Git.

### Новая версия приложения на сайте

Панель администратора → `app_releases` → новая запись: `versionCode`, `versionName`, что нового (`notes`)
и файл APK. Кнопка «Скачать» на сайте и окно «О beemes» в приложении сразу покажут новую версию.

## Приложение

Открыть папку `android/` в Android Studio. Подписанный APK: Build → Generate Signed App Bundle or APK.
Для проверки со своим компьютером: в `android/local.properties` строка `server.url=http://10.0.2.2:8091`
(эмулятор) — debug-сборка будет ходить на него, release всегда ходит на `https://kbast.ru`.

### Переезд на другой домен (например, с kbast.ru на beemes.ru)

1. В DNS нового домена — A-записи `@` и `www` с IP сервера.
2. На сервере — та же команда установки с новым доменом, а старый указать в `ALSO_DOMAINS`, чтобы старые
   версии приложения продолжали работать. База и переписка не трогаются:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/Kirill898990/beemes/refs/heads/main/server/install.sh \
     | ALSO_DOMAINS="kbast.ru" bash -s -- beemes.ru
   ```
3. В `android/app/build.gradle.kts` поменять `releaseServerUrl`, поднять `versionCode` и выпустить новую версию.

Проверка шифрования (совпадение с эталонными значениями):

```bash
cd android && ./gradlew :app:testDebugUnitTest
```

## Веб-версия и Windows

Веб-версия (`/web/`) шифрует так же, как телефон (WebCrypto: X25519, HKDF, AES-GCM, PBKDF2), поэтому переписка
общая: можно писать с телефона и с компьютера. Проверка совпадения с Android: `node server/tests/web-crypto.test.mjs`.

Приложение для Windows (`desktop/`) — окно с веб-версией. Установщик собирает GitHub (Actions → «Приложение для Windows»)
и выкладывает в Releases; постоянная ссылка:
`https://github.com/Kirill898990/beemes/releases/latest/download/BeemesSetup.exe`. Новая версия — поднять `version`
в `desktop/package.json`. Закрытое окно уходит в трей (значок пчёлки возле часов), чтобы приходили сообщения и звонки.

# beemes 🐝

Мессенджер для Android: личные чаты, звонки и видеозвонки, фотографии, бесплатные анимированные эмодзи
и настраиваемые профили. Все сообщения шифруются на телефоне — сервер хранит только шифр.

- `android/` — приложение (Kotlin, Jetpack Compose).
- `server/` — сервер на PocketBase: база, правила доступа, push-уведомления, звонки, сайт-визитка, страница звонка
  и **веб-версия** (`server/pb_public/web`, открывается по адресу `/web/`).
- `desktop/` — **приложение для Windows 10/11**: окно с веб-версией, работа в трее, автозапуск. Установщик собирает GitHub.
- `tools/fetch_emoji.py` — скачивает анимированные эмодзи Noto (Google, CC BY 4.0) в приложение.

## Как устроено шифрование

| Что | Как |
|---|---|
| Ключи | У каждого пользователя пара X25519, создаётся на телефоне при регистрации |
| Ключ чата | HKDF-SHA256 от общего секрета X25519, соль — id чата |
| Сообщения | AES-256-GCM, текст и служебные поля внутри шифра; AAD = `чат|отправитель` |
| Фото | Свой случайный ключ AES-256-GCM на каждое фото; ключ лежит внутри зашифрованного сообщения |
| Пароль | На сервер уходит не пароль, а PBKDF2-SHA256 (210 000 итераций) от него |
| Новый телефон | Копия закрытого ключа на сервере закрыта паролем (PBKDF2 + AES-GCM) |
| Проверка | «Код безопасности» в профиле собеседника — 20 цифр из обоих открытых ключей |
| Звонки | WebRTC (DTLS-SRTP), при необходимости через свой TURN-сервер (coturn) |
| Push | Firebase получает только зашифрованный текст, расшифровывает телефон |

Сервер видит, кто с кем переписывается и когда (без этого не доставить сообщение), но не содержимое.

## Сервер

Нужен свой сервер (VDS) с Ubuntu 24.04 и свой домен. beemes работает на `beemes.ru`; старый адрес
`kbast.ru` тоже открывается — на нём остаются старые версии приложения. В DNS домена добавьте две A-записи
с IP-адресом сервера: `@` (сам домен) и `www`. Затем на сервере под root:

```bash
curl -fsSL https://raw.githubusercontent.com/Kirill898990/beemes/refs/heads/main/server/install.sh \
  | ALSO_DOMAINS="kbast.ru" bash -s -- beemes.ru ПОЧТА_АДМИНИСТРАТОРА ПАРОЛЬ_АДМИНИСТРАТОРА
```

Что произойдёт:

1. beemes запустится в `/opt/beemes` на `127.0.0.1:8091` (служба `beemes`).
2. Поставится **Caddy**: он получает сертификаты https для домена и `www.` перед ним.
3. Поставится TURN-сервер для звонков (coturn) — через него идут звонки, когда телефоны не могут
   соединиться напрямую.

Если ставить beemes на сервер, где уже работает сайт «Простая химия», установка переведёт сайт школы
за тот же Caddy (его база не трогается) и возьмёт его TURN-сервер. Для этого у школы должна быть
версия с файлом `server/pb_hooks/proxy.pb.js`.

Повторный запуск той же команды обновляет beemes. Журналы: `journalctl -u beemes -f`, `journalctl -u caddy -f`.

### Домашний сервер без открытых портов (через туннель)

beemes может работать на своём компьютере дома, даже если порты на роутере открыть нельзя: компьютер сам подключается
к сервису-туннелю, а пользователи приходят через него. Домашний IP нигде не виден, снаружи к компьютеру не
подключиться. Ограничение: свой сервер для звонков дома не поднять — звонки соединяются напрямую (в мобильном
интернете иногда не соединятся).

Туннель — [Tuna](https://tuna.am) (серверы в России). Свой домен там доступен на платном тарифе «Профи».

1. **Tuna.** Зарегистрируйтесь на [my.tuna.am](https://my.tuna.am), подключите тариф со своими доменами.
2. **Домен.** В кабинете Tuna: **Домены → Добавить домен → Свой домен** → `beemes.ru`. Нужен вариант, где туннель
   работает прямо на `beemes.ru` (A-записи), без перенаправления на `www`: приложения ходят на `beemes.ru`, а при
   перенаправлении на другой адрес теряют вход. Tuna покажет DNS-записи — добавьте их там, где ведётся DNS домена
   (у регистратора; если это Cloudflare — с серым облаком, **DNS only**), записи AAAA для этих имён удалите.
   Проверка домена занимает от 15 минут до 2 часов.
3. **Ключ.** [my.tuna.am/api_keys](https://my.tuna.am/api_keys) → создать ключ с правом `tunnels:connect`. Никому его
   не пересылайте.
4. **Установка дома** (Ubuntu), почта и пароль — для панели администратора:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/Kirill898990/beemes/refs/heads/main/server/install.sh \
     | sudo TUNNEL=tuna bash -s -- beemes.ru ПОЧТА_АДМИНИСТРАТОРА ПАРОЛЬ_АДМИНИСТРАТОРА
   ```
   Установка спросит ключ Tuna (на экране его не видно) и подождёт, пока адрес откроется. Она закрывает все входящие
   соединения (SSH — только из домашней сети), включает автоматические обновления безопасности, запрещает компьютеру
   засыпать и раз в 15 минут сама забирает новое с GitHub. Программа Tuna работает под отдельным пользователем без
   прав, ключ лежит в файле, который видит только root. Повторный запуск той же команды обновляет beemes. Чтобы
   открывался и `www.beemes.ru`, добавьте его в Tuna отдельным доменом (CNAME) и запустите установку с `WWW=1`.
5. **Настройки в панели** `https://beemes.ru/_/`: ключ Firebase (`bm_settings`, см. ниже) и почта (Settings → Mail settings).

Настоящий адрес посетителя сервер определяет сам: через минуту после запуска он проверяет, каким заголовком туннель его
передаёт (в журнале `journalctl -u beemes` появится строка «Адрес посетителя берём из заголовка…»). Журнал туннеля:
`journalctl -u beemes-tuna -f`. В BIOS включите автозапуск после отключения света.

**Часовой пояс, выключение на ночь, резервные копии.** К команде установки можно добавить (после `sudo`, перед `bash`):

- `TIMEZONE=Europe/Moscow` — часовой пояс компьютера (проверить: `timedatectl`);
- `NIGHT=22:00-06:00` — каждый день в 22:00 компьютер выключается, а в 06:00 включается сам (его будят собственные
  часы). Пока он выключен, beemes не работает. Умеет ли компьютер включаться сам, проверьте так:
  `sudo rtcwake -m off -s 180` — он выключится и через 3 минуты должен включиться; если нет — включите в BIOS
  пробуждение по часам (RTC) и выключите режим ErP;
- `BACKUP_DIR=/mnt/backup/beemes` — папка для ежедневных копий базы и файлов, лучше на другом диске. Копия делается
  перед выключением на ночь (без расписания — в 04:00, beemes на минуту останавливается), хранятся 14 последних.
  Если диск с копиями не подключён, копия не пишется. Сделать копию сейчас: `sudo beemes-backup`.
- `BACKUP_DISK_ERASE=UUID` — один раз: отдать под копии второй диск целиком. UUID — любого раздела этого диска из
  `lsblk -f`. Диск **стирается**, на нём создаётся файловая система Linux, он подключается в `/mnt/beemes-backup`, и
  копии кладутся туда. Системный диск и диск, который сейчас используется, установка стирать отказывается.

Настройки запоминаются; отменить — `NIGHT=off`, `BACKUP_DIR=off`. Вернуть базу из копии:

```bash
sudo systemctl stop beemes
sudo mv /opt/beemes/pb_data /opt/beemes/pb_data.old
sudo tar -xzf /mnt/backup/beemes/beemes-ДАТА.tar.gz -C /opt/beemes
sudo systemctl start beemes
```

Через Cloudflare (`TUNNEL=cloudflare`, туннель создаётся в **Networking → Tunnels**) то же самое бесплатно, но в России
Cloudflare замедляют: туннель с домашнего интернета может не подключиться, а сайт — не открываться у посетителей.

### Push-уведомления (Firebase)

1. [console.firebase.google.com](https://console.firebase.google.com) → создать проект → добавить
   Android-приложение с пакетом `ru.beemes.app`.
2. Скачать `google-services.json` и положить в `android/app/` (в Git его нет). Без него приложение тоже
   собирается и работает, просто без уведомлений.
3. Настройки проекта → Сервисные аккаунты → «Создать закрытый ключ». Открыть панель администратора
   `https://beemes.ru/_/` → коллекция `bm_settings` → новая запись → вставить содержимое
   скачанного JSON в поле `firebaseKey`. Ключ никому не пересылайте и не кладите в Git.

### Почта и SMS (регистрация и вход по почте и телефону)

- **Почта** (коды при регистрации, входе и для 2FA): панель администратора `https://beemes.ru/_/` →
  Settings → Mail settings → включить «Use SMTP mail server» и вписать SMTP вашей почты
  (для Gmail: `smtp.gmail.com`, порт 465, логин — адрес Gmail, пароль — «пароль приложения» Google).
- **SMS** (регистрация и вход по номеру +7): зарегистрируйтесь на [sms.ru](https://sms.ru), пополните баланс,
  скопируйте API-ключ (api_id) → панель администратора → коллекция `bm_settings` → запись → поле `smsApiKey`.
  Необязательно: `smsDailyLimit` — сколько SMS в сутки всего (по умолчанию 300, защита от накрутки).
  Пока ключа нет, вариант «телефон» в приложении и на сайте просто не показывается.

### Новая версия приложения на сайте

Панель администратора → `app_releases` → новая запись: `versionCode`, `versionName`, что нового (`notes`)
и файл APK. Кнопка «Скачать» на сайте и окно «О beemes» в приложении сразу покажут новую версию.

## Приложение

Открыть папку `android/` в Android Studio. Подписанный APK: Build → Generate Signed App Bundle or APK.
Для проверки со своим компьютером: в `android/local.properties` строка `server.url=http://10.0.2.2:8091`
(эмулятор) — debug-сборка будет ходить на него, release всегда ходит на `https://beemes.ru`.

### Переезд на другой домен (так beemes переехал с kbast.ru на beemes.ru)

1. В DNS нового домена — A-записи `@` и `www` с IP сервера.
2. На сервере — та же команда установки с новым доменом, а старый указать в `ALSO_DOMAINS`, чтобы старые
   версии приложения продолжали работать. База и переписка не трогаются:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/Kirill898990/beemes/refs/heads/main/server/install.sh \
     | ALSO_DOMAINS="kbast.ru" bash -s -- beemes.ru
   ```
3. В `android/app/build.gradle.kts` поменять `releaseServerUrl`, поднять `versionCode` и выпустить новую версию.

Проверка шифрования (совпадение с эталонными значениями):

```bash
cd android && ./gradlew :app:testDebugUnitTest
```

## Веб-версия и Windows

Веб-версия (`/web/`) шифрует так же, как телефон (WebCrypto: X25519, HKDF, AES-GCM, PBKDF2), поэтому переписка
общая: можно писать с телефона и с компьютера. Проверка совпадения с Android: `node server/tests/web-crypto.test.mjs`.

Приложение для Windows (`desktop/`) — окно с веб-версией. Установщик собирает GitHub (Actions → «Приложение для Windows»)
и выкладывает в Releases; постоянная ссылка:
`https://github.com/Kirill898990/beemes/releases/latest/download/BeemesSetup.exe`. Новая версия — поднять `version`
в `desktop/package.json`. Закрытое окно уходит в трей (значок пчёлки возле часов), чтобы приходили сообщения и звонки.

### Уведомления на iPhone и в браузере, когда beemes закрыт

Web Push: на iPhone (iOS 16.4+) — если beemes добавлен на экран «Домой» («Поделиться» → «На экран „Домой“»),
в Chrome, Edge и Firefox — просто после разрешения уведомлений. Настраивать ничего не нужно: ключ сервера
(VAPID) создаётся сам в `pb_data/vapid.pem` — не удаляйте его, иначе подписки браузеров перестанут работать
до следующего открытия beemes. Сервер шлёт пустой «толчок»; текст забирает и расшифровывает само устройство
(`server/pb_public/web/sw.js`), так что ни Apple, ни Google его не видят.

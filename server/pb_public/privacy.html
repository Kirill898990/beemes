Политика конфиденциальности

Действует с 6 ноября 2026 года

Эта политика объясняет, какие данные собирает мессенджер beemes (приложения для Android и Windows, веб-версия и сайт, далее — Сервис), зачем и как их защищает. Регистрируясь, вы соглашаетесь с этой политикой.

Коротко

  • Сообщения, фотографии и записи о звонках шифруются на вашем телефоне. Сервер хранит их только в зашифрованном виде и прочитать не может.
  • Для регистрации не нужны ни номер телефона, ни почта — только @имя и пароль.
  • Мы не показываем рекламу и не продаём и не передаём данные для рекламы.

Какие данные хранятся на сервере

  • Профиль: @имя, имя, «о себе», фото, цвет профиля, эмодзи-статус. Профиль видят все пользователи Сервиса — так вас можно найти по @имени.
  • Время последнего входа («был в сети»). Его можно скрыть в настройках.
  • Ключи шифрования: открытый ключ (он виден собеседникам, это безопасно) и копия закрытого ключа, зашифрованная вашим паролем. Без пароля эта копия бесполезна; она нужна, чтобы войти на новом телефоне и не потерять переписку.
  • Пароль на сервер не отправляется: телефон получает из него отдельный код для входа, а сервер хранит только его хеш.
  • Сообщения и фото — в зашифрованном виде. Серверу видны служебные сведения, без которых сообщение не доставить: кто, кому и когда написал, тип сообщения (текст, фото, звонок), прочитано ли оно.
  • Звонки: служебные сообщения для соединения (кто, кому и когда звонил) хранятся не дольше суток.
  • Устройства: код для push-уведомлений вашего телефона.
  • Списки заблокированных пользователей и настройки чатов (без звука, скрытые).
  • Технические журналы: IP-адрес и время запросов — для защиты от атак и поиска ошибок.

Как устроено шифрование

У каждого пользователя есть пара ключей X25519. Общий ключ чата каждый телефон вычисляет сам из своего закрытого ключа и открытого ключа собеседника; сообщения и фото шифруются алгоритмом AES-256-GCM. Ключи хранятся на телефоне в защищённом хранилище Android, а в веб-версии и приложении для Windows — в хранилище браузера в виде ключа, который нельзя извлечь (им можно только пользоваться). Safari на iPhone, iPad и Mac так хранить ключ не умеет, поэтому там ключ хранится в хранилище сайта beemes на этом устройстве. При выходе из аккаунта ключ удаляется с устройства. Проверить, что переписку никто не подменяет, можно по «Коду безопасности» в профиле собеседника: у вас обоих цифры должны совпадать.

Голос и видео в звонках идут напрямую между телефонами и шифруются (DTLS-SRTP). Если напрямую соединиться нельзя, данные пересылает наш сервер, не расшифровывая их. Звонки не записываются.

Уведомления

В веб-версии и приложении для Windows уведомления показывает сам браузер или Windows, только если вы их разрешили; текст расшифровывается на компьютере.

На телефоне push-уведомления доставляет служба Firebase Cloud Messaging (Google). Через неё проходит только служебная информация и зашифрованный текст сообщения — расшифровывает его ваш телефон. Google получает код устройства для уведомлений. Уведомления можно выключить в настройках приложения или телефона.

Учебный профиль «Простой химии»

По желанию в приложении можно подключить аккаунт сайта «Простая химия», чтобы видеть свои оценки. Тогда телефон сам входит на сайт «Простой химии» и загружает оттуда оценки. Пароль не сохраняется — на телефоне остаётся только вход, зашифрованный ключом телефона. Оценки хранятся только на вашем телефоне: на сервер beemes они не отправляются, собеседники их не видят. Отключить профиль можно в любой момент, а при выходе из beemes он отключается сам.

Разрешения приложения

  • Микрофон и камера — только во время звонка.
  • Фото — только те, что вы сами выбрали для отправки или для профиля.
  • Уведомления — чтобы сообщать о новых сообщениях и звонках.

Кому передаются данные

Никому, кроме случаев, описанных выше (доставка уведомлений через Google), и случаев, прямо предусмотренных законом. Сервер находится в России. Зашифрованное содержимое сообщений Сервис не может раскрыть никому, потому что не имеет ключей.

Сколько хранятся данные

Пока существует аккаунт. Удалённые сообщения стираются с сервера сразу. Резервные копии сервера хранятся 7 дней, после чего удаляются.

Удаление аккаунта

Аккаунт можно удалить в приложении: «Настройки» → «Удалить аккаунт». Вместе с ним сразу удаляются профиль, ключи, все ваши чаты и сообщения в них (у собеседников эти чаты тоже исчезнут), устройства и списки блокировки. Из резервных копий данные пропадут в течение 7 дней.

Дети

Сервис не предназначен для детей младше 14 лет без согласия родителей.

Изменения политики

Если политика изменится, новая версия появится на этой странице с новой датой.
